# Diggings

Monorepo for **The Diggings & The Void**.

## Packages

- `packages/game` — Godot game project (formerly card-battler-prototype)
- `packages/atlas` — Narrative node tooling (formerly node-gen-web)

## Quick start

### Atlas (node tooling)
```bash
pnpm install
pnpm dev:atlas
```

### Game
Open in Godot:
```
packages/game/src/project.godot
```
