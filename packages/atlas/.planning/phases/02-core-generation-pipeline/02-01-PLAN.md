<objective>
Implement circuit breaker pattern to prevent runaway LLM costs when provider fails repeatedly.

Purpose: ERR-01 requirement mandates circuit breaker for repeated failures. Without it, the system will keep retrying failed LLM calls indefinitely, wasting API credits and time. The circuit breaker will "trip" after repeated failures and fail fast, giving the provider time to recover.

Output: New circuit-breaker.ts module with opossum integration, updated llm-client.ts to use circuit breaker wrapper.
</objective>
