# Map Node Types

Last verified: 2025-08-18

This file catalogs the types of map nodes and their effects during a run.

## Known Node Types (to verify against `data/map_nodes/` and scenes)

- Settlement: Shops, healing, events
- Mine: Gold-focused encounters, higher corruption risk
- Camp: Rest, remove a card, minor events
- Patrol: Authority enemies, bounties
- Pub: Brew-related events, buffs and debuffs
- Church: Sanity restoration, blessings
- Special: Story nodes spawned by backstory or events
