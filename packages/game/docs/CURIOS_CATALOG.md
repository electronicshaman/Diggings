# Curios Catalog

## Overview

Curios are persistent artifacts that provide lasting effects throughout a run. They represent relics, tools, and mystical items discovered during your journey through the Australian goldfields, each touched by either fortune or eldritch influence.

### Rarity Tiers

- **Common** (Yellow): Simple, reliable effects. Found frequently. Cost: 50-150 gold.
- **Rare** (Blue): Complex triggers and conditional bonuses. Cost: 150-300 gold.
- **Legendary** (Gold): Run-defining powers with significant impact. Cost: 300-500 gold.
- **Corrupted** (Purple): High power with corruption cost. Cost: 100-200 gold + 1-3 corruption.

### Mechanical Categories

- **Passive**: Always active effects
- **Triggered**: Activate on specific game events
- **Modifier**: Change game rules or mechanics
- **Resource**: Affect resource generation or management

### Class Synergies

Each curio has synergy ratings from 0.5 to 2.0:

- **0.5-0.8**: Poor synergy (works against class strengths)
- **0.9-1.1**: Neutral synergy
- **1.2-1.5**: Good synergy (complements class)
- **1.6-2.0**: Excellent synergy (amplifies class strengths)

## Implementation Notes

### Stacking Rules

- Stackable curios increase their effect linearly (e.g., 3x Lucky Nugget = +9 gold)
- Stack count is shown as a number badge on the curio icon
- Maximum stacks prevent additional copies from appearing in rewards

### Trigger Priority

1. Passive effects (always active)
2. Combat start effects
3. Turn start effects
4. Card played effects (in order played)
5. Damage/defense effects
6. Turn end effects
7. Combat end effects

### Balancing Guidelines

- Common: 5-15% power increase
- Rare: 15-30% power increase or significant rule change
- Legendary: 30-50% power increase or game-defining effect
- Corrupted: 40-60% power increase with significant drawback

### Unlock Conditions (Optional)

Some curios could require specific achievements:

- Ned Kelly's Helm: Defeat a boss without taking damage
- Golden Fleece: Accumulate 1000 gold in a single run
- The Last Drop: Win a combat with 1 HP remaining
- Aboriginal Songline Map: Visit every node type in one act

### Visual Effects

- Common: Simple glow effect
- Rare: Animated particle effects
- Legendary: Screen-wide effects on trigger
- Corrupted: Dark/purple corruption particles

### Save System Integration

Each curio in player inventory saves:

- Curio ID/name
- Stack count
- Trigger counters (for once-per-run effects)
- Any modified values
