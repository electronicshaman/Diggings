# Implementation Plan: DuelManager SRP Refactor

## Overview

This plan extracts 5 focused components from the monolithic DuelManager, following the Single Responsibility Principle. Each task builds incrementally, ensuring the game remains functional throughout the refactor.

## Tasks

    - Define timing constants
    - _Requirements: 1.1, 1.2, 1.3, 1.6_
  - [x] 1.2 Implement turn management methods
    - start_duel(): setup sequence, draw hands, start first turn
    - start_player_turn(): increment turn count, draw cards, emit signal
    - end_player_turn(): process end-of-turn effects, emit signal

    - end_enemy_turn(): emit signal, check for next turn
    - _Requirements: 1.1, 1.2, 1.3_
  - [x] 1.3 Implement win/loss condition checking
