# Vernacular — 1850s Australian Gold Rush

Period-appropriate vocabulary. Inject into prose-expander prompts.

| Term | Meaning |
|------|---------|
| digger | gold miner (NOT "miner") |
| colour | gold flakes |
| duffer | failed/empty claim |
| new chum | newcomer to the goldfields |
| old hand | experienced veteran |
| sly grog | illegal liquor |
| troopers | police |
| publican | bartender / innkeeper |
| mullock | waste rock |

## Usage Notes
- Use sparingly — flavour, not parody
- Mix with plain English; period-perfect dialogue rarely natural
- "Digger" is identity-defining; use whenever referring to gold-seekers as a class
