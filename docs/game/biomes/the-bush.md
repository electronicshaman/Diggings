# The Bush

**Atmosphere:** watchful silence, ancient indifference  
**Sensory:** eucalyptus oil, cicada drone, cracking twigs, heat shimmer, crow calls  
**Dangers:** bushrangers, getting lost, snakebite, thirst, things that watch  
**Voice:** the land doesn’t care if you live; survival is earned.  
**Antipatterns:** deadly Australia, everything wants to kill you, outback

**Act presence (1–4):** Arrival 2 • Fever 3 • Blasphemy 3 • Unmaking 2
