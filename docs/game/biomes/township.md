# Township

**Atmosphere:** desperate commerce, barely‑held order  
**Sensory:** canvas flap, mud squelch, tobacco smoke, coins clinking, distant hammering  
**Dangers:** debt collectors, licensing troopers, claim‑jumper rumors, sly grog poisoning  
**Voice:** transactions and threats; trust is currency.  
**Antipatterns:** wild west, saloon brawl, sheriff, frontier justice

**Act presence (1–4):** Arrival 4 • Fever 2 • Blasphemy 1 • Unmaking 2
