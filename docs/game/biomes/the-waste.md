# The Waste

**Sensory:** cracked earth, chemical taste, bone‑white sun, silence pools, rust smell  
**Dangers:** contamination, ghost‑touched, dehydration, the past repeating  
**Voice:** everything here failed or was abandoned; the ghosts remember why.  
**Antipatterns:** post‑apocalyptic, nuclear, zombie, wasteland warrior
